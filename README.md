# ApplyFlow – Job Application Tracker

ApplyFlow is a responsive job application tracking web application built with React. It helps job seekers organise their job applications, monitor their progress, and keep track of opportunities throughout their job search.

## Features

- **Personalised Dashboard:** Welcome screen and overview of job application statistics.
- **Application Management:** Add, edit, and delete job applications.
- **Application Status Tracking:** Track applications using Pending, Interview, Offer, and Rejected statuses.
- **Search and Filter:** Find applications by company name, job position, or application status.
- **Sorting:** Organise applications by date.
- **Analytics Dashboard:** Visualise application statistics with pie charts and monthly application trends with bar charts.
- **Settings:** Update profile information and manage application data.
- **Responsive Design:** Adapted for desktop and mobile screens.
- **Local Storage:** Uses browser local storage to save application and profile information.

## Getting Started

Follow these steps to run ApplyFlow locally.

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/edenobisesan10/ApplyFlow
   ```

2. Navigate into the project folder:

   ```bash
   cd ApplyFlow
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the application.
